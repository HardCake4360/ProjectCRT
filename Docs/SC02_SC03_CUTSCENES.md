# SC-02 / SC-03 컷씬

원문 `Project_CRT_SC01_SC03_컷씬_대본_원문.md`의 SC-02와 SC-03을 별도 씬의 플레이 흐름으로 연결했다. SC-01 완료 시 기존 연결대로 SC-02가 열린다.

## 실행

- `Assets/Scenes/ProjectCRT_SC02_SanRoom.unity`: 고정 3인칭 카메라로 시작. WASD 이동, 가까운 짐 상자에 E. 5개를 모두 정리하면 산이 소파로 이동하고 생각 대사 4개가 재생된다. 이름과 음성은 표시하지 않는다. 일어서고 카메라가 돌아온 뒤 맵 튜토리얼이 열린다. M으로 맵을 닫거나 열고, 샹그리아 버튼 또는 E/Enter로 SC-03으로 이동한다.
- `Assets/Scenes/ProjectCRT_SC03_ShangrilaReunion.unity`: 출입문 앞 거리에서 시작. WASD로 접근하고 E로 입장한다. 제레미와의 인사, 레베카와의 재회, 시간 경과, 소리의 발생, 프라이빗 홀 이동, 2번 룸 발견까지 원문 대사 76개를 재생한다. 마지막 레베카 대사 뒤 암전 상태로 종료한다.

대사 재생 중 E/Enter/Space를 누르면 먼저 현재 문장이 완성되고, 다시 누르면 다음 턴으로 넘어간다. ESC는 현재 컷씬 전체 건너뛰기다. F6은 이 씬의 컷씬 다시 보기, F8은 기존 컷씬 음성 방식 비교다. SC-04로의 연결은 아직 지정하지 않았다.

## 편집

`Tools > ProjectCRT > Cutscene Studio`에서 현재 씬의 `CutsceneStage`와 아래 시퀀스를 연결한다. 선택 턴 또는 전체 대본 미리보기, 포즈·카메라·시선 큐 편집을 기존 도구로 할 수 있다.

- `Assets/Settings/Prologue/SC23/SC02_UnpackingAndEvening.asset`
- `Assets/Settings/Prologue/SC23/SC03_ShangrilaReunion.asset`

씬의 `CAM - sc02-*`, `CAM - sc03-*` 오브젝트는 카메라 프리셋이다. `PATH - sc03-private-hall` 아래의 매듭은 후방 추적 경로다. 연기는 `Assets/Settings/Prologue/SC23/Animation`의 별도 클립에 저장했다. 원문의 대사는 함께 저장한 `SC02_DialogueSource.json`, `SC03_DialogueSource.json`과 대조할 수 있다.

## 캐릭터·소품·소리

산·레베카·제레미의 원본 모델과 샹그리아 FBX는 변경하지 않았다. 산은 기존 걷기 동작의 바인딩을 이 씬의 계층에 맞춘 복사본을 사용한다. 레베카는 기존 뼈대와 바 씬에서 사용하던 재질을 사용한다. 뼈대가 없는 제레미에는 원본 형태·재질을 보존하는 파생 메시와 간단한 연기용 뼈대를 추가했다. 모두 이 테스트의 포즈·몸짓용이며, 세밀한 표정·입 모양·모션 캡처 수준의 연기는 후속 조정 대상이다.

레베카의 대화·걷기에는 이후 무료 Quaternius 및 Anderson Rohr 동작을 리타기팅해 적용했다. 반응별 배정, 소품 접촉 보정과 이용 조건은 [REBECCA_SC03_ANIMATIONS.md](REBECCA_SC03_ANIMATIONS.md)를 참고한다.

입구 문, 카운터 뒤 문, 2번 룸 문, 병과 시간 경과 후 음료 상태도 컷씬 큐로 제어한다. 빗소리는 입장 후 작아지고, 복도에서는 재즈와 홀 소음이 멀어진다. 빗소리·문·재즈는 SC-01의 테스트 음원을 재사용하며 상자 정리·충격음·홀 소음은 합성한 임시 음원이다. NPC별 텍스트 음성은 기존 프로필을 재사용한다.

기존 NPC API와 사건 저장 슬롯은 호출하지 않는다. 이 두 씬의 짐 정리와 컷씬 상태는 씬 실행 중 상태다.

## 확인 자료

`Logs/SC23`에 제작, 모든 턴의 구도와 포즈 복원 검사, 실제 플레이 검사, 원본 보존 결과를 남긴다. 별도 Unity 프로젝트에서 제작하고 검증한 SC-02/03 씬과 새 리소스만 원래 프로젝트에 반영한다.

에디터 배치 렌더는 한 프레임 안에서 여러 포즈를 바꾸므로 GPU 스키닝 결과가 이전 포즈에 머물 수 있다. 정지 화면 검사에서는 현재 뼈 행렬로 만든 일시적인 CPU 메시를 렌더링하고 즉시 제거한다. 실제 게임의 렌더링은 기존 스키닝을 사용한다.

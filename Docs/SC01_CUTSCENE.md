# SC-01: 로스 시뮬라로 가는 길

기준 대본: `C:/Users/user/Downloads/Project_CRT_SC01_SC03_컷씬_대본_원문.md`의 SC-01 전체.

## 재생

`Assets/Scenes/ProjectCRT_SC01_TaxiArrival.unity`를 열고 Play를 누르면 자동 시작한다. 검은 화면과 비·엔진 소리에서 시작하여 택시 대화, CD 삽입, 도시 진입, 정차와 하차, 짐을 들고 입구로 향하는 장면을 재생한다. 종료 시 암전 후 `ProjectCRT_SC02_SanRoom`을 로딩한다. SC-02의 짐 정리·소파 컷씬·맵 튜토리얼과 SC-03의 샹그리아 입장·재회·발견 컷씬은 `Docs/SC02_SC03_CUTSCENES.md`에 정리했다.

- E / Enter / Space: 글자가 출력 중이면 전체 표시, 출력이 끝났으면 다음 대사.
- ESC: SC-01 전체 건너뛰기. 정상 종료와 동일하게 SC-02로 이동한다.
- F6: SC-01에서 재생이 멈춰 있을 때 다시 시작한다.
- F8: 기존 반복음 / 음절형 임시 보이스 비교. 실제 한국어 TTS나 녹음 대사가 아니다.

컷씬 중 자유 카메라와 배경 카메라 전환은 중지한다. `CutsceneDirector.Cancel()`로 디버그 취소하면 SC-01의 검수 조작과 인물 상태를 복원하며, 다음 씬으로 진행하지 않는다. Play 중단은 Unity의 일반 정지 기능을 사용한다.

## 연결한 내용

대본 원문 **25개 대사**를 유지하고 무대사 연출을 더해 **39개 턴**으로 구성했다. 기존 8개 카메라와 도시 추적·입구 접근 경로 2개를 사용한다. 일반 대사는 진행키를 기다리고, 주행·CD·하차 등 무대사 연출은 정해진 시간 동안 자동 진행한다. 이름과 글자별 보이스는 화자별로 구분한다.

산은 기존 `San.fbx`의 메시와 뼈대를 사용한다. 착석, 미세한 호흡과 말하기 동작, 창밖/기사 응시, 짧은 끄덕임, 요금 전달 동작, 하차, 도시 둘러보기, 가방 들기와 입구 접근을 연결했다. 기존 걷기 클립은 `san/...` 경로와 현재 모델의 `Armature.001/...` 경로가 달라 원본을 복사해 바인딩을 맞췄다. 원본 FBX·애니메이션은 수정하지 않았다.

택시 기사에는 모자·회색 머리·수염과 관절을 가진 임시 장면 모델을 사용했다. 운전, 미러 쪽 고개 돌리기, 대화, CD/볼륨 조작 동작을 배치했다. 최종 기사 캐릭터가 준비되면 `driver` 배우를 교체할 수 있다. 손가락과 소품 접촉은 후속 다듬기가 필요한 1차 연기다. 산에게 없는 얼굴 표정이나 립싱크 리소스를 새로 만든 것은 아니다.

택시 주행·정차·출발, 뒷문 열기/닫기, 와이퍼, CD 케이스 뚜껑과 디스크 삽입, 가방 이동은 실제 AnimationClip으로 연결했다. 정차·출발 때 기사가 차에 남도록 차량과 같은 이동을 사용한다. 촬영 구역 A/B/C는 턴에 따라 보이도록 구성하여 다른 구역의 배경이 화면에 섞이지 않게 했다.

산의 원본 색을 유지하는 SC-01 전용 재질 사본을 만들었다. 기존 재질의 과도한 밝기와 유리의 색 겹침을 보정했으며 원본 재질 파일은 유지한다. 실내 촬영 카메라를 위해 차량 메시 사본에서 앞쪽 조수석의 가림을 덜어냈다. 외부용 택시와 원본 `Car.fbx`는 유지한다. 기사 최종 외형, 실제 더빙, 세밀한 승하차·손 연기는 이후 교체/수정할 수 있다.

# No Sleep M3 제작 도구 구현 계획

작성일: 2026-10-05 (Asia/Seoul)  
기준: 실제 프로젝트 M1/M2, EditMode 178 / PlayMode 61 통과 기록  
상태: 실제 프로젝트에 세부 계획을 먼저 기록한 뒤 구현·자동 검증 완료

## 판단과 목적

M1/M2의 코드·진행 이력·검증 보고서를 확인했다. 안정적인 페이지/명령 ID, 공통·병렬 실행과 저장 v3가 마련되어 있으므로 다음 단계는 기존 추가 시스템 계획의 M3다. 새로운 전체 로드맵을 만들 필요는 없지만, 명령/페이지 복사와 맵 편집의 저장 호환 계약·Undo·검증 범위를 구체화해야 한다.

제작자가 코드 없이 대화·일회 보상·조건부 문·공통 호출·밤샘·접촉 전투를 조합하고, 여러 맵의 타일/이벤트를 편집하며 오류의 위치를 찾을 수 있게 한다. 기존 콘텐츠와 저장 키를 보존한다. M4 NPC 이동 및 M5 연출, M6 규칙 확정, M7 설정/자동 저장은 별도 단계로 둔다.

## 1. 전용 이벤트 편집기

- EventDefinition와 CommonEventDefinition를 여는 목록 기반 Event Editor를 추가한다. 페이지 추가·삭제·순서 이동·복제와 명령 검색·범위 선택·추가·삭제·이동·복제·복사/붙여넣기, 명령별 세부 필드 편집을 제공한다. 첫 창의 페이지 선택은 단일 선택이다.
- 기존 페이지/명령을 이동할 때 ID를 유지하고 페이지 복제는 새 pageId·commandId와 legacyPageIndex=-1을 사용한다. 일반 이벤트에서 공통 이벤트로 복사할 때도 같은 명령 모델을 사용한다.
- 붙여넣기는 참조 에셋을 유지한 깊은 복사를 사용한다. 내부 라벨을 충돌 없는 새 이름으로 바꾸고 Jump/If/Choice 대상을 함께 수정한다. 범위 밖 분기 대상은 기본 거부하며 같은 프로그램 안의 외부 라벨을 유지하는 선택을 명시한다. 삭제로 남은 점프가 깨지는 경우는 거부한다.
- 편집 도중 비어 있는 키·연결할 적/밤샘 데이터 같은 초안은 허용하되 진단한다. 구조 오류는 변경 전에 거부하고 부분 수정하지 않는다.
- 변경마다 Undo/Redo를 지원하고 한 작업은 한 단위로 되돌린다. 에셋 선택/Play 상태를 표시하고 Play 중 제작 데이터 편집은 잠근다.

## 2. 템플릿과 참조 목록

- Editor 전용 템플릿 에셋과 여섯 기본 조합(NPC 대화, 일회 보상, 조건부 문, 밤샘, 접촉 전투, 공통 호출)을 제공한다. 표시용 데이터와 실행 상태를 분리한다.
- 템플릿은 새 ID로 복사해서 적용한다. 사용자가 작성한 페이지를 자동으로 덮어쓰지 않는다. 필요한 맵·아이템·공통·밤샘·적 참조는 적용 전/후에 지정하고 누락을 정확하게 표시한다.
- 전역 스위치·변수·아이템 ID 선언 목록은 Editor 전용 StateKeyRegistry에 둔다. 기존 명령/조건에서 사용한 키와 공통·동료 정의도 수집하여 필드 선택 및 사용 위치 검색에 연결한다.
- 자유로운 상태 키를 금지하지 않는다. 읽기만 있고 선언/쓰기 위치가 없는 키는 경고로 표시하며 실제 누락 에셋·잘못된 명령 참조는 오류로 구분한다.
- 진단은 에셋/페이지/명령 위치로 이동할 수 있다. 전체 콘텐츠 검사에서 실제 오류만 실패 조건에 포함한다.

## 3. 맵 편집 확장

- 팔레트 검색·프리팹 미리보기, 사각형 선택·칠하기·복사/붙여넣기, 이벤트 다중 선택·복제·일괄 배치와 지역 ID 칠하기를 추가한다.
- 양 레이어의 타일 에셋 참조·시각 변형과 지역 ID, 선택한 이벤트의 상대 위치를 복사한다. 다른 팔레트에도 같은 타일 에셋을 연결하고 범위를 벗어나면 전부 거부한다. 복제 배치는 새 ID를 쓰고 기존 배치는 보존한다.
- 셀별 90도 회전과 시각적 높이 오프셋을 추가한다. 시각 오브젝트에만 적용하고 충돌/플레이어 이동면은 기존 XZ/Y=0 격자를 유지한다. 실제 다층 이동을 구현한 것으로 표시하지 않는다.
- 기존 맵의 새 필드는 0 기본값을 사용하고 크기 변경 시 겹친 셀 데이터를 유지한다. 맵 복제는 새 mapId와 배치 ID를 발급하고 이벤트 정의 참조는 유지한다.
- 지역/충돌 표시를 제공하고 한 편집 작업의 Undo/Redo·에셋 저장/재로드를 검증한다.

## 4. 맵 연결 검사

- 맵 배치의 직접 이동, 중첩 공통 호출, 전경 요청에서 맵 이동 명령을 모은다. 재귀/방문 수 상한을 적용한다.
- 목적지 누락·범위 밖·이동 불가, 등록되지 않은 목적지와 제작자가 선언한 필수 연결 누락은 오류로 보고한다.
- 조건부 연결과 돌아오는 연결이 없는 경우는 구분해 표시한다. 의도된 단방향/필수 연결 정책은 Editor 전용 레지스트리에 기록한다.
- 정적 연결 검사는 실제 게임의 자원·퀘스트 조건을 만족한 도달 가능성을 증명하지 않는다. 기존 샘플을 임의로 연결하거나 스토리 조건을 변경하지 않는다.

## 5. 저장·검증·전달

런타임 저장 포맷은 v3를 유지한다. 이번 새 데이터는 제작 에셋이며 기존 완료·거래·체크포인트 ID를 유지한다. 제거한 저장 참조를 자동으로 다른 페이지에 연결하지 않는다.

검증은 명령 분기 복사·ID 보존/분리·Undo/Redo·템플릿의 실제 해석, 맵 참조/지역/시각 변형·복제·경계 실패 원자성, 공통/전경 경로의 연결 진단과 기존 239개 회귀 검사에 집중한다. Unity 컴파일·Validate Content·EditMode/PlayMode 결과를 실제 실행한 뒤 기록한다. 자동 검사와 사람의 편집기 사용/플레이·빌드 검증을 구분한다.

기존 에셋·씬·패키지·URP/입력 설정과 사용자 저장 파일을 보존한다. 검증 후 실제 C:\Users\user\Documents\GitHub\projectNoSleep에 코드·에셋·가이드·보고서를 적용하고 SHA-256을 확인한다. 작업마다 PROJECT_HISTORY를 갱신하며 다음 작업은 M4 준비 상태를 판단한 뒤 결정한다.

## 실행 결과

전용 창·템플릿 6종·상태 키/사용 위치와 맵 일괄 편집·지역/시각 변형·연결 검사를 구현했다. 공통 프로그램에 조합을 추가할 때 조합의 마지막 End를 제외하고 기존 종료 앞에 넣어 연속 조합이 실행되게 했다. 읽기 전용 진단은 원본과 중첩 공통의 누락 ID를 자동 수정하지 않는다. 외부 Inspector 변경 후 선택 위치와 누락 페이지/명령 목록의 Undo 복구도 보완했다.

Unity EditMode 230/230, PlayMode 63/63, 합계 293개 통과(기존 239개 포함, 신규 54개). 실패/건너뜀 0개. 템플릿 생성 및 재실행의 파일·ID 보존과 콘텐츠 검사도 통과했다. 보고서와 검증 제한은 VERIFICATION에 기록한다. 사람이 화면을 보며 확인하는 편집기 조작/플레이·배포 빌드·대형 맵 성능은 이번 자동 검증에 포함하지 않았다.

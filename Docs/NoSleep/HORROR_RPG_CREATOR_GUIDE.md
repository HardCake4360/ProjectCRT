# No Sleep 호러 RPG 프로토타입 가이드

Unity 6000.0.32f1 / URP 17.0.3. 구현 계획은 `HORROR_RPG_IMPLEMENTATION_PLAN.md`를 따른다. 수치·대사·전투·이동 비용은 조정 가능한 프로토타입이며 재앙의 원인, 동료의 행방과 결말을 확정하지 않는다.

## 실행과 진행

`Assets/NoSleep/Scenes/NoSleepHorrorPrototype.unity`를 열고 Play를 누른다. 에셋이 없는 최초 환경에서는 **No Sleep > Create Horror Prototype**을 실행한다. 이미 있는 씬과 데이터는 보존한다. 기존 `NoSleepDemo.unity`도 계속 사용할 수 있다.

1. 제목 화면에서 **새 게임**을 선택한다. 뉴스가 끝나면 방의 문을 통해 병원으로 간다.
2. 병원의 보관함에서 각성제를 확보한다. 의료인의 증언을 듣고 민에게 말을 걸면 동행과 과격한 공격이 해금된다.
3. 환승 구역으로 이동한다. 준의 다른 증언을 듣고 관찰 행동을 익힌다. 병원으로 돌아가 누락된 증언을 들을 수 있다.
4. 밤샘 장소에서 합주나 롤러코스터를 선택한다. 새벽까지 진행되고 일지에 좋은 추억이 남는다.
5. 두 증언과 밤샘을 마치면 다음 통로로 간다. 긴 이동 후 혼자가 되지만 추억과 배운 행동은 남는다.
6. 마지막 통로의 목적지와 상호작용하면 도달 상태를 기록한다. 원인이나 정식 결말은 제시하지 않는다.

길 위에서 보이는 형체에 접촉하면 전투가 시작된다. 다른 길로 돌아갈 수도 있다. **물러나기**는 보상과 격파 상태를 주지 않으며, 같은 접촉에서는 다시 시작되지 않는다. 트리거를 벗어나 다시 들어가면 재전투할 수 있다.

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키 | 카메라 기준 이동 |
| Shift | 달리기 |
| E / Enter / Space | 상호작용·대사 진행 |
| 위/아래, E / Enter | 대사 선택 |
| Tab / I | 상태·소지품·각성제 사용 |
| J | 목표·단서·일지·추억 |
| F5 | 슬롯 1 저장; 기존 파일은 덮어쓰기 확인 |
| F9 | 불러오기 슬롯 목록 |
| Esc | 현재 메뉴로 돌아가기 |

일반 메뉴 버튼은 마우스 또는 방향키·Enter로 조작한다. 제목/패배 화면 위에 슬롯이 열리거나 덮어쓰기 확인창이 열리면 배경 버튼은 선택할 수 없다. 제목 화면의 이어하기는 현재 씬에서 사용 가능한 6개 슬롯 중 가장 최근 저장을 선택한다.

## 저장 정책과 복원

저장 위치는 `Application.persistentDataPath/NoSleep/Saves/slot-0.json`부터 `slot-5.json`이다. UI에서는 슬롯 1~6으로 표시한다. Windows의 일반 경로는 `AppData/LocalLow/<CompanyName>/<ProductName>/NoSleep/Saves`이며 실제 Company/Product 설정에 따라 달라진다. 기존 API의 슬롯 0~99와 기존 파일 이름을 유지한다.

v2 저장에는 맵·정확한 위치·방향, 능력치·스위치·셀프 스위치·변수·소지품에 더해 경과 시간·시작 시각·피로·각성 만료, 쇠약 기준 능력치, 목표·단서·일지·추억, 동료 명부/동행과 해금 행동이 포함된다. UTC 저장 시각·맵 이름·목표 요약을 목록에 표시한다.

현재는 v1/v2 파일을 읽고 다음 저장부터 v3로 기록한다. v2의 모든 진행 필드를 보존하며 원자적 거래 기록과 명시적인 병렬 체크포인트를 추가한다. 안정 ID와 이전 정책은 [EVENT_SYSTEM_GUIDE.md](EVENT_SYSTEM_GUIDE.md)를 참고한다. 맵 ID와 이벤트 배치 ID를 유지해야 기존 진행이 연결된다. 기존 시스템 데모 저장은 해당 맵 카탈로그를 가진 데모에서 불러온다. 새 호러 씬은 다른 맵 ID를 사용하므로 목록에서 사용할 수 없는 맵을 표시한다.

파일은 검증한 독립 스냅샷을 임시 파일에 쓴 뒤 교체하고 직전 파일을 `.bak`로 보관한다. **이전 백업**은 읽기만 하며 주 저장 파일을 자동으로 덮어쓰지 않는다. 파일 손상, 알 수 없는 맵, 이동 불가 위치 또는 파일 접근 오류는 현재 맵·상태·플레이어를 보존한다.

대사·이벤트·전투 중에는 저장/불러오기를 차단한다. 상태창·슬롯창에서는 저장할 수 있고 제목·패배 화면에서는 불러올 수 있다. 체력 0은 패배 화면으로 연결된다. 새 게임은 슬롯을 삭제하지 않는다.

## 시간·피로·쇠약

`Assets/NoSleep/Data/Horror/Rules/SurvivalSettings.asset`에서 조정한다.

- 기본 **AuthoredCosts**: 이동 이벤트와 전투가 지정한 분을 소비한다. 일반 이동과 대사 읽기는 시간을 소비하지 않는다.
- 선택적 **Realtime**: `realSecondsPerGameMinute`마다 게임 1분이 흐른다. 이벤트·전투·모든 모달 메뉴에서 멈춘다.
- 오전 6시~오후 8시는 낮, 나머지는 밤이다. 기본 피로 증가량은 분당 0.02, 밤 배율은 1.7이다.
- 피로 100만으로 자동 사망하지 않는다. 이동 속도 하한은 0.65이며 전투 공격력에도 하한이 있다. 실제 수면/실패 규칙은 후속 기획 대상이다.
- 기본 각성제는 체력 6을 소비하며 120분 동안 유효 피로를 35 낮춘다. 남은 체력이 비용 이하이면 사용할 수 없다. 실제 피로는 지워지지 않으며 효과가 끝나면 다시 드러난다.
- 최대 체력과 힘은 날짜에 따라 감소하고 적의 능력치도 감소한다. 기본 기간은 14일, 기간/하한/감소량은 에셋에서 바꾼다. 샘플 이동 이벤트의 비용은 별도로 조정해야 7일 여정으로 단축된다.
- 시작 시각과 능력치 기준값은 저장한다. 불러오기 때 기준값을 다시 잡아 쇠약이 중복되지 않는다.

밤샘 활동은 `NightActivityDefinition`에서 새벽 시각, 밤샘 피로 배율, 체력/정신력 회복과 추억을 설정한다. 낮에 시작하면 밤 8시까지의 평상시 피로를 먼저 부과한다. 동행 필요 여부와 활동 ID를 사용하며, 반복 체험도 가능하지만 같은 추억은 한 번만 기록한다. 샘플은 두 선택을 한 장소에서 대사와 시간으로 표현하며 놀이공원 별도 맵·탑승 연출은 후속 범위다.

## 제작 데이터와 이벤트

**Assets > Create > No Sleep > Horror RPG**에서 시간 설정, 아이템 효과, 동료, 밤샘 활동을 만든다. 적은 **No Sleep > Enemy**에서 만든다. 씬의 `NoSleepBootstrap`에 시작 맵/모든 맵, 생존 설정, 각성제, 동료 목록과 제목 화면 여부를 연결한다. 동료 모델은 현재 기본 도형으로 따라다니며 충돌 판정은 가지지 않는다.

| 신규 이벤트 명령 | 필드와 효과 |
| --- | --- |
| AdvanceTime | 분 단위 비용 |
| SetObjective | key=목표 ID, text=목표, intValue=여정 단계 |
| RecordClue | key=단서 ID, speaker=제목, text=내용; 중복 기록 방지 |
| JoinCompanion / LeaveCompanion | key=동료 ID |
| ClearParty | 활성 동료만 제거, 명부·추억은 유지 |
| UnlockAction | key=행동 ID; aggressive/observe를 전투에서 사용 |
| UseItem | item=아이템 효과; 실패하면 이벤트 완료/후속 명령 중단 |
| StayAwake | nightActivity=밤샘 활동; 실패하면 완료/후속 명령 중단 |
| StartEncounter | enemy=적, key=승리 셀프 스위치(기본 defeated) |
| ReachDestination | 목적지 도달 기록 |

새 조건은 Day, EffectiveFatigue, Companion(현재 동행), Clue, ActionUnlocked다. Day/EffectiveFatigue는 숫자 비교, 나머지는 ID와 기대 bool을 사용한다. 전투 패배·취소·이탈은 일회성 이벤트 완료를 기록하지 않고 뒤 명령을 실행하지 않는다. 적의 마지막 페이지에 defeated 셀프 스위치 조건과 visible/blocksMovement=false를 설정하면 승리 후 사라진다.

접촉 전투는 임시 턴 선택 방식이다. 공격/방어/이탈이 기본이며 과격한 공격은 체력 8과 각성 효과, 관찰은 즉시 받은 피해 감소와 다음 공격 증가를 가진다. 각성제도 한 턴을 소비한다. 모든 수락된 행동은 5분을 소비하고 50턴이면 전투를 취소한다. 동료 보조 피해는 최대 3이다. 전투 중 적 능력치는 시간이 지나면 같은 날짜 규칙으로 줄어든다.

제작 후 **No Sleep > Validate Content**를 실행한다. 안정적인 ID, 조건과 후속 명령을 함께 검사하고 저장한 파일로 재방문하여 반복 보상·목표 역행이 없는지 확인한다. 공통/병렬 이벤트, NPC 이동 경로, 최종 아트·애니메이션·조명·오디오, 완성된 1~2주 콘텐츠와 배포 빌드는 후속 구현 대상이다.

# No Sleep 제작자 가이드

기준: Unity 6000.0.32f1, URP 17.0.3. 기존 URP 설정을 사용한다.

## 시작하기

1. `Assets/NoSleep/Scenes/NoSleepDemo.unity`를 연다. 씬이 아직 없다면 Unity 메뉴 **No Sleep > Create or Open Demo**를 실행한다.
2. Play를 누른다. 첫 대사를 닫은 뒤 안내인에게 이동하여 대화한다.
3. 열쇠를 받는 선택지를 선택하고 북동쪽 문으로 가면 다른 맵으로 이동한다.
4. 보관함은 처음 열 때만 소지금을 준다. 저장 후 불러와도 이 상태가 유지된다.

| 조작 | 키 |
| --- | --- |
| 이동 | WASD / 방향키 / 게임패드 왼쪽 스틱 |
| 달리기 | Shift / 왼쪽 스틱 누르기 |
| 상호작용·대사 진행 | E / Enter / Space / 게임패드 A |
| 선택지 이동 | 위·아래 / W·S / 십자키 |
| 상태창 | Tab / I / 게임패드 Start |
| 상태창 닫기 | Esc / 게임패드 B |
| 빠른 저장 / 불러오기 슬롯 | F5 / F9 |
| 여정 일지 | J |

저장·불러오기는 대사·전투·전경 이벤트가 끝난 뒤 실행한다. 병렬 이벤트만 실행 중이면 안전한 명령 경계에서 저장할 수 있다. 상태창에 6개 저장 슬롯과 불러오기 버튼이 있다. F5는 슬롯 1을 저장하며 기존 파일을 덮어쓸 때 확인한다. F9는 슬롯 목록을 연다. 호러 RPG 제작은 `HORROR_RPG_CREATOR_GUIDE.md`, v3 저장과 공통·병렬 이벤트는 [이벤트 시스템 가이드](EVENT_SYSTEM_GUIDE.md)를 참고한다.

M3에서 추가한 전용 Event Editor, 템플릿·키/참조 조회와 사각형 맵 편집·지역/시각 변형·복제·연결 검사는 [M3 제작 도구 가이드](M3_AUTHORING_GUIDE.md)를 참고한다.

## 맵 만들기

**No Sleep > Map Editor**에서 맵 에셋을 선택하거나 새로 만든다. 맵 ID는 저장과 셀프 스위치의 기준이므로 다른 맵과 겹치지 않는 영문 ID를 사용한다. 플레이어가 방문한 맵의 ID와 이벤트 배치 ID를 변경하면 기존 저장의 상태 연결이 달라진다.

크기와 셀 크기를 정하고 타일 팔레트에 `TileDefinition`을 등록한다. **Assets > Create > No Sleep > Tile**에서 타일을 만든다. `walkable`은 이동 가능 여부, `prefab`은 실제 3D 모델, `material`과 `fallbackColor`는 기본 큐브 표시, `height`는 기본 타일 두께/벽 높이다. 이동 가능한 지면 프리팹은 상단이 로컬 Y=0이 되게 제작한다. 셀 중심은 `(x * cellSize, 0, z * cellSize)`이며 지면과 장식 레이어를 별도로 칠할 수 있다.

타일과 NPC 프리팹은 시각적 모델로 취급한다. 복제된 프리팹의 물리 콜라이더와 Rigidbody는 런타임 맵 생성 시 비활성화하고 타일의 이동 가능 여부, 격자 충돌과 이벤트 페이지가 이동 차단을 결정한다. 원본 프리팹 에셋은 수정하지 않는다. 런타임 맵 루트는 위치/회전/스케일 기본값을 유지한다.

브러시로 칠하고 지우개로 비운다. 채우기/비우기는 선택한 레이어에 적용한다. 시작 지점은 이동 가능한 지면 위에 설정한다. 이벤트 배치 목록에 고유 ID, 좌표, 이벤트 정의와 회전을 입력한다. Undo를 지원한다. 씬 미리보기는 생성된 전용 루트에만 적용한다. 실제 플레이 맵은 런타임에 에셋에서 생성된다.

씬의 `NoSleepBootstrap`에는 시작 맵과 방문 가능한 모든 맵 목록을 등록한다. 다른 맵이 저장에 포함될 수 있으므로 카탈로그에 등록해야 새 실행에서도 불러올 수 있다.

## NPC와 이벤트 만들기

**Assets > Create > No Sleep > Event**에서 정의를 만든다. 이름과 선택적 프리팹을 지정하고 페이지를 추가한다. 같은 정의를 여러 장소에 배치할 수 있으며 셀프 스위치는 배치별로 구분된다.

페이지는 **목록의 마지막부터** 조건을 검사한다. 모든 조건이 맞는 첫 페이지를 사용한다. 기본 대사를 앞 페이지에 두고, 스위치/변수/소지품 조건에 따른 페이지를 뒤쪽에 둔다. 조건에 맞는 페이지가 없으면 보이지 않고 이동도 막지 않는다. `visible=false`는 표시만 숨기므로 숨겨진 접촉/자동 이벤트는 실행될 수 있다. 보이지 않는 이벤트는 일반적으로 `blocksMovement=false`도 설정한다.

- **Action**: 가까이 다가가 E로 실행.
- **PlayerTouch**: 플레이어가 트리거 영역에 들어올 때 실행.
- **Autorun**: 유효 페이지가 자동 실행. 단발 연출은 `runOnce=true` 또는 마지막에 셀프 스위치로 다른 페이지로 전환해야 한다.
- **Parallel**: 입력을 잠그지 않는 제한된 백그라운드 실행. 조건 감시, 게임 시간 대기, 원자적 지급과 전경 실행 요청을 지원한다.
- **runOnce**: 해당 배치의 해당 페이지를 성공적으로 마친 경우에만 안정적인 페이지 ID에 완료 상태를 저장한다. 기존 콘텐츠는 **Upgrade Event Identities**로 원래 페이지 번호를 보존한 뒤 재정렬한다. 페이지/명령 ID를 수동 변경하지 않는다.

명령 목록의 `type`에 따라 필요한 필드를 설정한다.

| 명령 | 작성 방법 |
| --- | --- |
| ShowDialogue | `speaker`, `text`. 빈 화자는 독백. E로 타이핑을 마치고 다시 E로 진행 |
| ShowChoices | 질문 `text`, 선택지별 `text`와 이동할 `targetLabel`. 빈 목적지는 다음 명령 |
| SetSwitch | `key`, `boolValue` |
| SetVariable / AddVariable | `key`, `intValue` |
| SetSelfSwitch | 해당 배치의 `key`(예: A), `boolValue` |
| AddItem | 아이템 ID `key`, 수량 `intValue`. 음수면 차감, 최소 0 |
| AddGold | 금액 `intValue`. 음수면 차감, 최소 0 |
| Wait | 대기 초 `seconds` |
| TransferPlayer | 대상 맵 `map`, 좌표 `cell` |
| IfCondition | `condition`이 **거짓일 때** `targetLabel`로 이동. 참이면 다음 명령 |
| Jump / Label | `targetLabel`로 이동 / 해당 위치에 `label` 정의 |
| End | 실행 종료 |

선택지 분기 끝에는 `End` 또는 `Jump`를 넣어 다음 분기로 이어지지 않게 한다. 명령 실행 전 중복/없는 라벨, 빈 키와 잘못된 대기 값을 검사한다. 실행량 제한으로 무한 점프를 중단한다. `__nosleep_`로 시작하는 셀프 스위치는 내부 완료 기록에 예약되어 있다.

## 저장과 검증

저장 파일: `Application.persistentDataPath/NoSleep/Saves/slot-0.json`. 상태, 현재 맵 ID, 플레이어 위치와 방향을 저장한다. 기존 파일 교체 시 `.bak`를 남긴다. 잘못된 포맷/버전/목적지는 오류 메시지를 표시하고 현재 게임 상태를 유지한다. 세션 전체 데이터를 중간 이벤트에서 저장하지 않는다.

**No Sleep > Validate Content**로 맵 ID, 시작점, 이벤트 ID, 명령 라벨과 이동 목적지를 검사한다. **Window > General > Test Runner**에서 EditMode와 PlayMode 테스트를 실행한다. 생성한 샘플 씬은 빌드 씬 목록에 추가되며 기존 씬은 보존된다. 샘플을 빌드할 때 실행 시작 씬은 NoSleepDemo로 설정한다.

## 현재 제한과 확장 지점

기본 시스템과 호러 RPG 샘플, 공통·병렬 이벤트, 실행 디버거, 전용 이벤트/맵 제작 창과 NPC 경로/일과 이동을 구현했다. 제목/저장 슬롯/목표·일지·동료·추억 UI는 현재 사용할 수 있다. NPC 모델은 기본 캡슐이며 화면/음향 연출, 복수 목표·단계 카탈로그와 최종 게임용 아트는 후속 계획에 있다. 현재 이동은 평면이며 높이 차가 있는 3D 지형과 자유 시점은 별도 확장이 필요하다. 큰 맵은 셀마다 오브젝트를 생성하므로 성능 측정 후 필요한 청크/풀링 최적화를 적용한다. UI는 운영체제의 한국어 폰트를 사용하며 배포 시 라이선스가 확보된 폰트 에셋을 포함하는 단계가 필요하다.

다음 작업을 진행할 때는 `IMPLEMENTATION_PLAN.md`를 확인하고 변경 내용과 검증 결과를 `PROJECT_HISTORY.md`에 추가한다.

2026-10-05의 [추가 시스템 계획](SYSTEM_EXPANSION_PLAN.md) 중 M1~M4를 구현했다. `NoSleepSystemsLab.unity`에서 공통 호출·병렬 지급·시간 대기·전경 요청을 확인하며 **No Sleep > Event Debugger**에서 정지/한 단계/취소 및 NPC 셀/예약/일과/실패 이유를 조회한다. [M3 제작 도구](M3_AUTHORING_GUIDE.md), [M4 NPC 제작](M4_NPC_GUIDE.md)과 별도 `NoSleepNpcLab.unity`를 참고한다. 현재 저장은 v4(v1~v3 읽기)이며 이동 중 저장은 현재 칸 이동을 마친 뒤 처리한다. 삭제되거나 매핑할 수 없는 과거 완료·체크포인트·NPC 참조는 불러오기 오류로 보고한다. 후속 작업은 M5 연출이다.

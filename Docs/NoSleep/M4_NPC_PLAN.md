# No Sleep M4 NPC 이동·일과 구현 계획

작성일: 2026-10-05 (Asia/Seoul)
기준: M3 실제 적용, EditMode 230 / PlayMode 63 통과
상태: 계획 선기록 후 구현·Unity 자동 검증 완료. 실제 적용 결과는 PROJECT_HISTORY.md에 기록

## 목적과 범위

기존 로드맵의 M4를 진행한다. NPC/보이는 적의 같은 맵 내 격자 이동·일과·상태 복원을 기존 이벤트/모달/저장 소유권과 연결한다. 기존 이벤트·맵·저장 ID 및 제작 콘텐츠를 유지한다. 맵 간 NPC 이동, 애니메이션/전환/카메라·음향 연출, 본편 규칙과 최종 콘텐츠는 후속 범위다.

## 제작 데이터

MapEventPlacement에 선택적 NpcDefinition 참조를 추가한다. 참조가 없는 기존 이벤트는 기존 방식으로 동작한다. 이벤트 정의는 페이지·모델·접촉/대사를 유지하며 NPC 정의는 안정 npcId, 속도·기본 경로·일과·감지/추적 설정을 가진다. NpcRouteDefinition은 안정 routeId, 셀 목록과 반복 여부를 가진다. 일과는 게임 날짜/시각 및 기존 StateCondition으로 선택하며 명시적 영구 위치 변경을 우선한다.

ID는 제작 시 발급하고 이동·에셋 이름 변경 때 유지한다. 복제에 새 ID를 발급하는 메뉴와 읽기 전용 콘텐츠 검사를 제공한다. 경로의 셀은 바인딩한 맵에서 검증하고 여러 맵에 같은 경로를 쓰면 각각 검사한다.

## 이동·점유 계약

4방향 격자 탐색은 결정적 순서와 노드/재시도 상한을 사용한다. NPC는 자기 자신을 점유 검사에서 제외하며 다른 NPC의 현재/예약 칸, 고정 이벤트, 플레이어 점유와 지형을 확인한다. 이동 직전 다시 예약하고 현재 칸과 다음 칸을 동시에 보호한다. 서로 칸을 교환하거나 길이 막히면 제한된 재탐색/대기 후 실패를 반환하며 겹침·무한 대기를 허용하지 않는다.

배경 경로/순찰/접근은 대사·전투·일반 모달·디버거 정지 중 멈춘다. 전경 이벤트가 명시한 목적지 이동만 전경 잠금 안에서 실행하며 완료/실패/취소를 반환한다. 취소·맵 교체·새 게임·로드 때 이전 세대의 이동과 예약을 제거한다. 보간된 위치/탐색 경로는 저장하지 않는다.

전경용 이동·바라보기·정지·자동 일과 복귀 명령을 기존 enum 숫자를 유지하며 끝에 추가한다. 대상은 현재 맵의 배치 ID 또는 호출자 배치이며 공통 호출에서도 호출자 문맥을 유지한다. 이동 실패는 후속 보상/페이지 완료를 진행하지 않는다. 영구 변경 선택은 저장 상태에 기록하고 자동 일과가 덮어쓰지 않는다.

## 일과·보이는 적

같은 일과의 체크포인트는 맵 왕복/로드 때 이어간다. 게임 시간이 크게 뛰거나 선택한 일과가 바뀌면 이전 분의 경로를 모두 재생하지 않고 새 경로 시작점으로 재평가한다. 목적지 점유/지형이 불가능하면 이동시키지 않고 실패를 표시한다. 영구 위치 우선 계약을 유지한다.

보이는 적은 동일 이동 서비스의 정지/순찰·거리/시야가 제한된 감지·접근·추적 종료를 사용한다. 접촉은 기존 EventObject의 전투 요청과 단일 전경 소유권을 사용한다. 격파 후 숨김/비활성 페이지로 전환하여 저장/로드 뒤에도 전투가 재지급되지 않는다. 랜덤 인카운트와 새로운 수면 사망 규칙을 추가하지 않는다.

## 저장 v4와 복원

GameState에 배치별 NpcState를 추가한다. mapId/placementId/npcId, 유효 셀·방향, routeId/waypointIndex, scheduleId/lastEvaluatedMinutes와 영구 위치 플래그를 저장한다. 새 영구 필드가 있으므로 저장 포맷은 v4로 올리고 v1/v2/v3를 계속 읽는다. NPC 기록이 없는 구버전은 제작 배치에서 초기화한다. 기존 완료·거래·체크포인트·생존/여정/동료 상태를 보존한다.

이동 중 저장은 새로운 스텝을 멈추고 현재 스텝만 완료한 칸 경계에서 예약 저장한다. 슬롯/백업 쓰기와 명확한 예약/완료 알림을 구분한다. 이동/로드/새 게임은 이전 예약을 취소한다. 저장 실패는 기존 파일과 라이브 상태를 바꾸지 않는다.

분리된 후보에서 ID/배치·경로/체크포인트·셀·방향·NPC끼리/고정 이벤트 충돌을 검증한다. 제거된 NPC/경로 참조를 다른 것으로 조용히 바꾸지 않는다. 플레이어 위치만 가장 가까운 유효 셀(동률 행 우선)로 피하며 불가능하면 로드를 거부한다. 실패한 전환/로드는 상태·맵·플레이어·NPC 위치/경로·이벤트 예약을 복구한다. NPC 저장은 전체 등록 맵을 검증하고 실행 객체는 현재 맵에서만 재생성한다.

## 제작 도구·샘플·검증

NPC/경로 Inspector, Map Editor의 바인딩, 참조/콘텐츠 검사와 전경 명령 UI를 연결한다. Play 중 제작 변경은 잠그고 진단은 원본을 수정하지 않는다. 별도 NpcLab 2개 맵에 두 이동 NPC·공통 대사·시간 점프 일과·순찰/접근 적·맵 왕복/저장을 배치한다. 생성 메뉴 재실행은 기존 내용을 보존한다.

기존 293개 검사를 유지하며 탐색/예약/교차/길막힘·모달/대화 정지·전경 이동 실패/취소·시간 점프·영구 위치 우선·보이는 적 접촉/격파·이동 중 예약 저장·v1~v3 이전·잘못된 후보/전체 롤백을 의미 있는 EditMode/PlayMode 검사로 검증한다. 컴파일·콘텐츠 검사·샘플 생성/보존과 실제 적용 해시를 확인하고 이력/가이드를 갱신한다. 자동 검사와 실제 화면 조작/플레이/성능/배포 빌드 평가를 구분한다.

## 구현 결과와 확정한 경계

Unity EditMode 270 / PlayMode 93, 합계 363개 통과(기존 293개 + 신규 70개). 실패/건너뜀 0개다. 기존 미래 버전 거부 검사 두 건은 새 현재 버전 v4에 맞춰 입력을 v5로 변경했다. 보고서는 Docs/Validation/NpcEditMode.xml 및 NpcPlayMode.xml이다.

이동 속도는 초당 격자 칸 수다. 임시 Face는 기존 자동 이동 여부를 보존하고, Step은 실행 중 전경 명령의 소유 NPC만 움직인다. 이동 중 고정 이벤트가 차단 페이지로 바뀌면 예약 칸을 재검사하고 안전한 시작 칸으로 복귀한다. 격파 후 숨김/비차단 NPC는 접근·접촉·상호작용을 멈춘다.

플레이어의 저장 칸이 지형상 이동 불가하면 기존 거부 정책을 유지한다. 유효 지형의 NPC/고정 이벤트 겹침은 가장 가까운 유효 칸으로 복구한다. NPC 경유지는 숫자 index로 저장하므로 배포 후 같은 routeId의 경유지 재정렬/삭제는 자동 호환되지 않는다. NPC의 임시 정지·탐색/보간/재시도는 파일에 보존하지 않는다.

예기치 않은 생성/외부 구독자 예외로 맵을 다시 만들 때는 상태·NPC 보간·예약·전경 큐·디버거 정지를 복구하고 배경 이벤트는 지속 체크포인트에서 재생성한다. 임의 Coroutine 스택의 복원은 지원하지 않는다. 자세한 사용법과 제한은 M4_NPC_GUIDE.md에 기록한다.

- 시간 점프/일과 변경은 현재 정지점/경로 시작점을 재평가한다. 점유된 목적지의 이전 위치/체크포인트를 유지하고 제한 재시도 후 이유를 표시한다. 막힌 자동 정지점 복귀도 저장/재로드 뒤 재평가한다.
- 보이는 적의 순찰·거리/벽/모서리 시야·접근·추적 종료를 연결했다. 물리와 근접 접촉은 한 진입으로 합쳐 이탈/취소 직후 겹침에서 반복 전투하지 않게 했다. 격파 후 숨김/비차단 페이지의 NPC는 접근·접촉·상호작용을 멈추고 저장 복원 뒤에도 비활성이다.

- 독립 후보의 모든 맵 NPC 참조/셀/충돌을 먼저 검증한다. 유효 지형의 플레이어 겹침은 거리/행 우선으로 피하며 NPC 충돌은 거부한다. 일반 전경 맵 이동에서는 기존 State 객체/실행 세대를 유지해 후속 명령이 라이브 상태에 적용된다. 예기치 않은 전환 예외는 NPC 보간/예약/큐/디버거 정지도 복구한다.
- NPC/경로 Inspector·Map Editor 브러시/배치/복사·Content Browser/검사·Event Editor 명령과 Event Debugger NPC 상태를 연결했다. 신규 NoSleepNpcLab 두 맵과 제작 가이드, 상위/추가 계획·기존 가이드·README를 갱신했다.
